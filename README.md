# 📞📲 Mini Contact List Manager (React)

A Persian-friendly contact management app with CRUD operations. Part of the bootCamp program called BotoStart.

# 📽️ Demo:

## 🚀Run Instructions:

1. **Clone the repo**

   ```bash
   git clone https://github.com/MohammadaliRashidfarokhi/ContactList.git
   cd ContactList

   ```

2. **Install dependencies**
   
   npm install

3. **Run the app**
   
   npm run dev
